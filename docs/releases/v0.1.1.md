# Hostpin v0.1.1

Hostpin v0.1.1 makes the one-command Linux host installation fit direct server
deployments more naturally.

## Changes

- `install-server.sh` now listens on `0.0.0.0:8080` by default.
- A fresh interactive installation asks for the public URL through `/dev/tty`.
- Pressing Enter uses the detected private address and port 8080.
- Existing installations preserve their configuration without asking again.
- `--public-url` and `--listen` remain available for automation and reverse
  proxy deployments.
- Public plain-HTTP URLs remain blocked; use HTTPS for Internet enrollment.

## Install

```sh
curl -fsSL https://github.com/chnzzh/hostpin/releases/latest/download/install-server.sh | sudo sh
```

The installer uses SQLite by default and preserves `/etc/hostpin/hostpin.yaml`
and `/var/lib/hostpin` on upgrades.

## 中文说明

本版本将 Linux 服务端默认监听地址调整为 `0.0.0.0:8080`。首次安装会询问公开
