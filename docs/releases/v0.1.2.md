# Hostpin v0.1.2

Hostpin v0.1.2 adds an explicitly acknowledged public-IP HTTP deployment mode
for operators who need direct access without a domain or certificate.

## Changes

- A public HTTP URL is accepted only after a dedicated interception warning.
- Non-interactive server installation requires `--allow-insecure-http`.
- The generated server configuration records `allow_insecure_http: true`.
- Each Agent presents a second warning before enrolling over public HTTP.
- Non-interactive Agent installation requires `--allow-http`.
- Private-network HTTP behavior and the `0.0.0.0:8080` default are unchanged.

## Install

Interactive installation:

```sh
curl -fsSL https://github.com/chnzzh/hostpin/releases/latest/download/install-server.sh | sudo sh
```

At the URL prompt, enter `http://<public-ip>:8080` and explicitly accept the
warning. HTTPS remains strongly recommended: public HTTP does not protect
administrator credentials, enrollment PINs, sessions, Agent tokens, metrics,
or scripts from interception.

## 中文说明

本版本允许无域名、无证书时直接使用 `http://<公网IP>:8080`，但服务端安装器会先
显示明文传输风险并要求二次确认；每台 Agent 注册时还会独立确认。无人值守服务端和
Agent 安装必须分别使用 `--allow-insecure-http` 与 `--allow-http`，不会静默降级。
