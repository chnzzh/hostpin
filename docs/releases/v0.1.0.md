# Hostpin v0.1.0

Hostpin v0.1.0 is the first public release of the self-hosted, PIN-enrolled
server monitoring platform.

## Highlights

- SQLite-first single-binary deployment, with optional PostgreSQL 16+.
- Lightweight cross-platform Agent and PIN self-enrollment—no need to create a
  node in the dashboard first.
- Live and historical host metrics, monthly traffic and correction, probes,
  alerts, billing/expiry data, and encrypted one-click backup/restore.
- NAT-safe distributed latency nodes. A regular monitoring node can also act as
  a latency measurement point without reinstalling its Agent.
- Telecom, Unicom, and Mobile latency/loss history on every node detail page.
- Chinese/English responsive dashboard and pinned Komari public-theme
  compatibility.
- No web shell, PTY, arbitrary command execution, container control, or log
  collection.

## Install

Download `hostpin-server-linux-amd64` or `hostpin-server-linux-arm64` and the
matching `.sha256` file from this release. SQLite is the default database.
After starting the server, open `/setup` and follow the dashboard's Agent
installation command.

Release assets include 13 Agent targets, two Linux server targets, individual
SHA-256 sidecars, `SHA256SUMS`, license/notice files, a third-party license
bundle, and an Ed25519-signed Agent update manifest.

## Upgrading from preview builds

Back up the database, `master.key`, themes, configuration, and old binaries,
then replace the server binary. Database migrations run automatically and
preserve existing monitor and probe-only nodes. Existing protocol-v1 Agents do
not need to be re-enrolled.

## Known limits

v0.1.0 is single-site, single-admin, and single-instance. PostgreSQL-to-SQLite
reverse migration, online database migration, HA, RBAC, multi-tenancy,
container monitoring, logs, and remote execution are outside this release.
